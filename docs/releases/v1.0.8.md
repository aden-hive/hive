# Hive v1.0.8: Turn Context

> A package installed next to Hive can show a queen something before each of her turns, and
> recall of past conversations reads Chinese.

## New

- **Turn context.** A package registers a factory in the `hive.turn_context` entry-point group,
  and `hive serve` starts it when its section of `configuration.json` turns it on
  (`{"turn_context": {"<name>": {"enabled": true}}}`). Before a queen answers a user message,
  each started package gets her id and the message; the text it returns reaches her as a
  `<system-reminder>` just ahead of the message, and stays in the conversation like any reminder.
  Use it for context that depends on what was said, such as examples in her voice or notes from
  your own store. A package slower than 5 seconds, or one that raises, is skipped for that turn;
  one that fails to start is logged and left out. With none installed, nothing changes. See
  [building-on-hive.md](../building-on-hive.md#turn-context-show-a-queen-something-before-each-turn).

## Fixed

- **Recall of past conversations reads Chinese.** It only took Latin letters and digits as search
  terms, so a Chinese message contributed none: what matched was the time stamped on every
  message and a channel's sender header. Each turn then brought in the same unrelated old excerpts,
  and the queen repeated lines from them. Recall now leaves out the time stamp and the sender
  header, ignores long numbers such as account ids, and matches Chinese and Japanese by
  two-character pieces.
- **A failed model call stays out of chat apps.** A model gateway built on Hive can answer a
  failed upstream call with Hive's own `[Error: LLM call failed: …]` text as an ordinary reply.
  The queen's loop took it for her answer, so a channel sent the error into the chat, and the stall
  check judged it and reminded her to act, which called the failing model again. Channels now hear
  that text as an error (hive-onebot logs it and sends nothing), and the stall check skips the turn.

## For code built on Hive

New in `hive`: `TurnContext` and `TurnContextHost`. `AgentContext` has a new optional field,
`turn_context_provider`.

`aden-tools` is released at the same version: its recall changed, and the two packages pin each
other exactly.
