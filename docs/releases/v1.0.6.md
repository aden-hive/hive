# Hive v1.0.6: Channels

> Chat apps can talk to queens from inside `hive serve`, and scripts fetch credentials without
> the agent ever seeing them.

## New

- **Channels.** A package installed next to Hive can register a chat-app integration in the
  `hive.channels` entry-point group. `hive serve` starts it when its section of
  `configuration.json` turns it on (`{"channels": {"<name>": {"enabled": true}}}`). Each
  conversation in the app (a group, a private chat) is a queen session that also shows in the
  dashboard. The channel opens or resumes it with `ChannelHost.open_session`, sends messages
  with `send` (images are saved into the session like dashboard attachments, and big photos are
  scaled down), and hears the queen with `subscribe`: each finished model turn's text, `ask_user`
  questions, the files she hands over with `attach_file`, and failed model calls, in order.
  Opening a queen or starting a new chat with her in the dashboard never picks or stops a
  channel's sessions. `GET /api/channels` lists the installed channels as running, off or failed.
  See [building-on-hive.md](../building-on-hive.md#channels-reach-queens-from-a-chat-app).
- **`hive-cred`**, from the desktop runtime. A script fetches a credential when it uses it:
  `TOK=$(hive-cred token <id> --account <alias>)`. OAuth tokens are refreshed on each call, and
  the value never passes through the conversation. `hive-cred browse` and `hive-cred inspect`
  show what is connected, without values.

## Changed

- The `credentials` tool keeps `collect`, `attach` and `detach`. Its `browse`, `inspect` and
  `reveal` actions now reply with the `hive-cred` command to run instead. `reveal` put the
  decrypted secret into the conversation, and from there into logs. The queen's
  `list_credentials` tool is gone for the same reason; `hive-cred browse` replaces it.

## Fixed

- A message that reached a queen while she was still starting (just after her session was
  created or resumed) started a second queen. It now waits for her.

## For code built on Hive

New in `hive`: `Channel`, `ChannelHost`, `ChannelError` and `QueenOutput`.

`aden-tools` is released at the same version: its credential adapter changed, and the `tools`
extra pins it exactly.
