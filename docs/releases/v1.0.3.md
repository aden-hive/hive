# Hive v1.0.3: The Right Version

> The dashboard shows Hive's version, and `hive --version` prints it.

## Fixed

- **The dashboard's version.** The sidebar showed `v0.1.0` whatever Hive was installed, because
  the dashboard took its version from `core/frontend/package.json`, which is never released. It
  now takes it from `core/pyproject.toml`, the version of the `aden-hive` package it ships in.

## New

- **`hive --version`** prints the installed Hive's version.

`aden-tools` is released at the same version, unchanged, because the `tools` extra pins it exactly.
