# Hive v1.0.7: Follow Through

> A judge catches a queen who says she'll do something and ends her turn without doing it, and
> reminds her once.

## New

- **Stall check** (Settings → Developer, off by default). Some models write "on it, running it
  now" and end the turn without the tool call that would do it. With the stall check on and a
  judge in the Judge slot, every queen turn that ends waiting for you goes to the judge: your
  message, her last reasoning and reply, and the tools she called. When the judge says she
  announced an action she never took (a probability at or above the slot's `threshold`, 0.5 by
  default), she gets one reminder to carry it out. That happens at most once per message you
  send, so a wrong judgment can't loop. Turning the check on or off, or changing the judge,
  applies to running sessions at once. `HIVE_STALL_CHECK=1` or `0` overrides the toggle.
- **The Judge slot** (Settings → AI Model → Judge). It names a protocol, an endpoint, a model
  and a key, so no vendor is built into Hive:

  ```json
  "judge": {"protocol": "typesafe", "api_base": "<endpoint>", "model": "<model>", "api_key": "...", "threshold": 0.5}
  ```

  The one protocol so far is `typesafe`: TypeSafe's `/systemone` endpoint answering a "noul"
  (probability) question, for example with Jev. A judge isn't a chat model, so saving it skips
  the chat key check.
- **Runtime logs show the server's log.** Settings → Developer → Runtime logs opens a drawer
  with the last 500 lines of the Hive server's log, tracebacks included, updated every 2
  seconds; warnings and errors are red. The drawer came from the desktop app and was always
  empty in `hive serve`. `GET /api/runtime-logs?after=<seq>&boot=<boot>` serves it.

## Changed

- **No first-run wizard.** Without a model, the chat shows a one-line notice above the message
  box with a link to Settings → AI Model. A failed model call shows as a card with the same link,
  with the error behind a Details toggle, instead of the raw error text. The setup wizard that
  blocked the dashboard is gone.

## Fixed

- The dashboard asked for an LLM key on every refresh when the key was saved as `llm.api_key`
  in `configuration.json`, because it only looked at the provider's environment variable. It
  now checks the key Hive would actually use.

## For code built on Hive

`aden-tools` is released at the same version. It hasn't changed, but the two packages pin each
other exactly.
