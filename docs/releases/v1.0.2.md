# Hive v1.0.2: The Whole App from PyPI

> `pip install "aden-hive[tools]"` now installs all of Hive: the queens' built-in tools, the
> browser and the dashboard. Run `hive open`. Projects built on Hive get a starter
> [AGENTS.md](https://agents.md) for their coding agents.

## What's new

- **The whole app installs from PyPI.** `aden-tools` now ships every package Hive imports from
  it. Before, the terminal tools (shell, background jobs, terminal sessions, ripgrep search), the
  memory tools (search, and the queens' recall of earlier sessions) and the chart tools were
  missing: they only worked inside a checkout of this repository. A queen in a pip install
  could not load any of her built-in tools. All five tool groups (29 tools) now load from the
  installed packages, the same as from a checkout.
- **The dashboard ships in the wheel.** `aden-hive` carries the built dashboard, and the server
  serves it when there is no checkout to serve it from. `hive serve` and `hive open` show it.
- **`templates/derivative/AGENTS.md`.** A starter AGENTS.md for projects built on Hive. Copy it to
  the new repository's root. It gives coding agents the rules for building on Hive, a working
  example, how to test without a model, and the gotchas.
- **`aden-tools` is published to PyPI**, at the same version as `aden-hive`. The `tools` extra pins
  it exactly, since the two are released together.

## Changed

- `aden-hive`'s source distribution leaves out `frontend/node_modules`, and includes the built
  dashboard so a wheel built from it has one.
- The package READMEs (which are their PyPI pages) link to GitHub with absolute URLs.

## Building the distributions

```sh
cd core/frontend && npm ci && npm run build && cd ../..
uv build --package aden-hive
uv build --package aden-tools
```

Without the dashboard build, the `aden-hive` wheel is still made, without a dashboard, and the
build prints a warning. CI's **Package** job builds both, installs them into a clean virtualenv,
and checks that every tool group loads and that the dashboard is served.
