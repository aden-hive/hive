# Hive v1.0.9: Ask the Judge

> A channel can put its own yes/no questions to the judge, so a chat app can let the queen speak
> up when it fits.

## New

- **`ChannelHost.judge`.** The judge in Settings → AI Model → Judge (the `judge` slot, for
  example TypeSafe's Jev) used to answer only the stall check's question. A channel can now ask it
  any yes/no question about a `state` it passes, optionally with `criteria` saying what counts as
  yes and as no. It gets back the probability of yes, or `None` when no judge is set up or the
  judge can't answer right now. A chat-app channel can use it, for example, to decide whether the
  queen should speak up in a group where nobody addressed her. Each call is one request to the
  judge's vendor. See
  [building-on-hive.md](../building-on-hive.md#channels-reach-queens-from-a-chat-app).

## Changed

- The stall check now asks the judge through the same code. How it behaves is unchanged.

## For code built on Hive

New: `ChannelHost.judge(question, state, *, criteria=None)`.

`aden-tools` is released at the same version. It hasn't changed, but the two packages pin each
other exactly.
