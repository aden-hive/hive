# Hive v1.0.10: Her Own Model

> Each queen can run on a model of her own, set from her profile in the dashboard, and `hive serve`
> stops within seconds.

## New

- **A queen's own model.** Every queen used the main model (Settings → AI Model → LLM). Now a
  queen can have her own: open her profile (Org Chart → her card) and, under **Model**, pick a
  saved provider, edit the section as JSON, or go back to the main model. It is stored under
  `queen_llm` in `configuration.json`, by queen id, in the main slot's shape, and gets the same key
  check when saved. Her running chats switch on their next model call; her context window follows
  her model; changing the main model leaves her on hers; her colony workers use it too unless
  `worker_llm` is set. The key can be literal, `api_key_env_var` or in the credential store; the
  subscription logins (Claude Code, Codex, Kimi, Antigravity) work only for the main model. See
  [configuration.md](../configuration.md#a-queens-own-model).

## Fixed

- **`hive serve` stops within seconds.** Stopping it started a last memory reflection for every
  session (up to five model calls each) and waited a minute for open connections, which dashboard
  event streams never close, so a service manager often killed it first. The reflections now get 6
  seconds and connections 3; if the process is still there 5 seconds after that, every thread's
  stack goes to stderr and it exits.

## For code built on Hive

- `GET /api/queen/{queen_id}/llm` and `PUT /api/queen/{queen_id}/llm` (`{"section": {...} | null}`)
  read and set a queen's own model.
- `LiteLLMProvider.reconfigure()` takes an optional `api_key_resolver`, to replace the callable
  that re-resolves the key before each call.

`aden-tools` is released at the same version. It hasn't changed, but the two packages pin each
other exactly.

If you run `hive serve` under NSSM with `AppRotateOnline 1`, NSSM itself can stay in
STOP_PENDING for a minute after Hive has exited; `AppRotateOnline 0` avoids it (files still
rotate at each start).
